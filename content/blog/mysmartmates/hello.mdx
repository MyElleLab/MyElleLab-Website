part of the sentence rather than interrupting it.

## A second-level heading

Headings are Playfair, like every other heading on the site. The list below is
here to check bullet spacing and marker colour:

- A first item, short.
- A second item that runs on a little further so it wraps onto a second line
  and the leading between wrapped lines can be judged.
- A third item.

A fenced block follows, which is the real thing being tested:

```ts
export function suiteBlogPath(suite: Suite) {
  // The slug is the single source of truth for the route.
  const slug = suiteSlug(suite);
  return `/blog/${slug}`;
}
```
